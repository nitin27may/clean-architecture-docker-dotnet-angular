# Architecture Decisions

Records of the decisions that shaped this codebase, kept so the reasoning survives the
people who made it. Each one states the context, the decision, and what it costs.

{: .note }
An ADR is not a rule. It is a record of what was decided and why, at a point in time.
Superseding one is normal; silently ignoring one is not.
